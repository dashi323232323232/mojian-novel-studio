# AI 写作（本地模型）

## 一句话

软件自带一页「AI 写作」：它调用本机的 Qwen3-4B 小说模型，读写项目里的 `上下文.md`，一章一章往下写。

## 怎么用

1. 左侧选中一个项目 → 展开 → 点 **AI 写作**（在「音频制作」下面）
2. 首次使用点 **部署到本地**，等十几秒，状态变「运行中」
   - 模型：`out\Qwen3-4B-novel-Q6_K.gguf`（3.31 GB）
   - 服务：`out\llamacpp-cuda\llama-server.exe`，端口 8080
   - 显存占用约 4.2 GB，3070Ti 上 60–90 tok/s
3. 左边是 **上下文.md**，第一次会自动生成六节模板，按项目实际情况改（人物性格、伏笔、时间线）
4. 右边填「本章要点」，点 **生成正文**
5. 出来以后：
   - **存到硬盘** → `%APPDATA%\大师小说工作台\ai-writer\<项目ID>\`
   - **写入章节** → 直接进项目章节树，内容页立刻能编辑

## 上下文.md 的六节（这是模型的长记忆）

| 小节 | 作用 |
| --- | --- |
| 一、核心设定 | 题材、世界、主角、金手指、主线终点 |
| 二、人物卡 | 性格特点 / 说话风格 / 底线雷点 —— 防止人设崩 |
| 三、未回收伏笔 | 表格：编号 / 埋设章节 / 内容 / 计划回收 |
| 四、章节摘要 | 每章一句话概要 + 关键事件（自动追加） |
| 五、时间线与当前进度 | 当前章节、故事内时间、地点、上一章结尾状态 |
| 六、文风约束 | 人称、节奏、禁用词、目标字数 |

写完一章，模型会自动：
- 在「四、章节摘要」里追加本章条目
- 在「三、未回收伏笔」表格里加新伏笔行
- 更新「五、时间线」的当前章节与结尾状态

**别手动删这几节标题**，模型靠它们定位插入位置。

## 命令行版（不想开软件时）

```bash
python writer.py new 我的小说                  # 建项目 + 上下文模板
python writer.py write 我的小说 --hint "本章要点" --words 2500
python writer.py holes 我的小说                # 看未回收伏笔
```

需要先在 1234 端口（LM Studio）或 8080 端口（软件部署）有 OpenAI 兼容服务：

```bash
set NOVEL_API=http://127.0.0.1:8080/v1
```

## 想用 LM Studio / 其他前端

同一份 `out\Qwen3-4B-novel-Q6_K.gguf` 直接拖进 LM Studio 即可，推荐参数：

- 上下文 8192
- temperature 0.85，top_p 0.9，repeat_penalty 1.05
- GPU offload 全部（显存需 ≥ 4.5 GB）

## 训练信息（想重训时看）

- 底座：Qwen3-4B-Instruct-2507，LoRA rank 32 / alpha 64，3 epoch / 990 步
- 语料：6.52 M 字，重点 72.9%（番茄 68 本：火影/海贼/柯南/鬼灭同人 + 宋明春秋三国穿越权谋 + 病娇言情）+ 补充 27.1%
- 最终 loss 2.36
- 脚本：`tools/train_min2.py`（远端）、`out/merge_lora.py`、`out/final_gguf.py`
